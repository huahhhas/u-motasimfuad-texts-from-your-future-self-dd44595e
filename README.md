One funny text message from your future self, sent back to the present you.

## The entry

> hey, it's you from 2031. stop buying courses — you own 47 unfinished ones and the toaster is the only thing paying rent now.

124 characters. `main.py` prints the line and writes it byte-identical to `/output/entry.txt`.

## Run

```sh
python3 main.py
```
